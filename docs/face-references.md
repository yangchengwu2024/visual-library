# 面貌线稿首批

三张线稿由许可明确的照片经 image_gen 近似重建正面，首批用于检索与资产设计取用。线稿提供面貌起点，角色、妆发和表现按当前设计形成；先看实际图片。

每条记录的 `image_index=0` 是长边512 JPEG，`image_index=1` 是提线母版。完整实际提示、源图对应和规格保存在详情与来源清单。
