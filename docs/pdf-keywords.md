## 使用与回查

先选主体与用途，再从表中挑少量材质、技法或姓名线索，并分别记录模型、版本、输入图和输出图。若要判断某个词是否有效，应固定其他条件做对照；本补遗没有执行生图复现。

这里只自存事实性短词与原创整理说明，原图片及完整 prompt 均回到原 PDF 查阅。未对无文本层的扫描资料强行补词，也未把 PDF 全文或图像作为开放许可资源收录。
