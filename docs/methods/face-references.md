# 面貌线稿参考资料

需要面貌起点时，先检索本库准备好的面貌线稿，实际看图后以线稿作为面貌图片输入，结合角色要求与 asset-design 当前表现分支的文字规则从零生成，再沿成图和用户反馈发展。线稿、照片及角色图片按任务需要取用；缺少合适素材时再搜索补充。

[查看已收录面貌线稿](../face-references.md)

## 收录与查找

现成线稿、照片及角色图片可采用 `image_reference` 类型，保存实际图片与来源。没有实际提示词时保存空字符串；生成式提线的完整实际提示词保存在该线稿的 `prompt` 中。工具、模型与参数按实际记录，未知时保留未知；原有图文案例保留其原始提示词要求。

线稿作为日常主要调用素材，源图保留出处和重新处理依据。复用来源记录的 `source_metadata` 保存源图与线稿的对应关系、可得的文件哈希、提线方法、工具和处理参数；缩小或压缩版本关联线稿母版，并记录尺寸、格式与文件大小。实际提示词由权威 prompt 字段承担。原图与线稿的保存位置和公开范围按各自来源确定。

扩大准备前，用已有可用线稿比较拟采用的提线方式与文件规格，并实际生成检查效果、面貌差异和处理成本。沿选定规格分批处理，保留母版和失败项以便续接。

沿现有分类组织，用“脸部参考”“面貌线稿”、面貌描述及画面角度等关键词帮助查找，同时利用旧案例中适用的图片。姓名和作品名在有依据时记录；没有姓名的图片同样可以使用。匹配是否成立以实际看图为准。

新来源先按明确范围手动收录。写入本公开仓库的图片需记录允许公开保存的依据、作者和必要署名；其他来源的获取与使用条件单独记录。

## 取图参与资产设计

优先按资料库当前可用的 `search_cases → get_case → get_case_image` 读取，使用确切案例ID、版本和图片索引，跨调用传入 `expected_commit`。连接不可用时按[使用说明](../usage.md)读取仓库文件。

MCP预览用于看图，参与生成的图片按生图接口要求取得：取得指定提交下的原图，必要时临时保存到当前任务目录并核对原图哈希；能使用工具返回图片的宿主，按接口引用对应图片。仅有网页链接或缩略图展示，不能视作已传入生成。

按 `asset-design` 既有规则说明参考职责和采用范围：面貌线稿提供起点，角色、妆发与渲染表现由当前设计和表现分支文字形成。实际调用 `image_gen` 并检查角色是否好看、符合要求、候选面貌是否有可见区别。原型相似程度按具体任务确定；角色采用后由项目采用图承接身份。实际输入来源、提示和成图保存在当前制作项目。
