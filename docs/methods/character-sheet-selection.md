# 角色设定：概念板与输入依赖

## 适合比较的问题

当需求是“找角色设定板”时，首先要区分：案例是在展示一种角色概念板结构，还是依赖用户提供的角色参考图来保持既有设计。

- [ROGUE VIPER 游戏角色概念设定板](../../cases/case-awesome-gpt-image-2-473-7b4b6261b32a/v1.md)：包含角色三视、装备/表情信息和环境设定，适合借鉴多区域概念板的组织方式。
- [Brutalist Freestyle 角色设定表](../../cases/case-awesome-gpt-image-2-512-a85add6ba440/v1.md)：原始 prompt 要求上传角色参考图，当前归档没有该输入，因此适合当作“需要替换输入”的模板候选，不应当作无需输入即可复用的完整案例。

## 选择逻辑

- 需要研究角色设定板如何组织多个区域：先看 ROGUE VIPER。
- 需要沿用自己的角色形象并保持轮廓、装备或服装关系：可以参考 Brutalist Freestyle 的版式，但必须准备自己的角色输入图。

“有成图”不等于“输入条件齐全”。使用前应打开指定版本，查看图片角色、完整 prompt 和 `review_status`；本页没有执行重新生成，也没有证明身份保持或逐像素复现。
