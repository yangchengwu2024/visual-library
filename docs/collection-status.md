# 资料完整性与复核说明

[返回画廊](gallery.md) · [复核记录](reference-audit-20260909.md)

资料总数包含图文案例和风格参考，不代表每条都已实测生成或核验全部使用条件。

- **已复核**：已核对本次来源图文和输入要求；不等于每个画面细节都吻合，也不代表已用模型重新生成。
- **待复核**：尚未逐图核对，或存在模型/图文/角色不明确之处；不等于图片文件缺失。具体原因在案例页。
- **缺少必要输入图**：已发现原指令依赖特定输入，而本库没有那份独立输入；不能将成品裁切或截图缩略图当作原输入已保存。
- **风格参考**：可参考画面、风格词或参数；缺少完整生成指令者不会冒充完整提示词案例。

本轮已实际读完原有541条提示词并查看对应图片，新增22条同样完成图文核对。当前已复核 525 条；31 条看过后仍有来源或图文疑点；7 条缺少特定必要输入。疑点不是未完成的看图任务，具体条目和原因见[全库复核记录](reference-audit-20260909.md)。

通用模板要求用户提供自己的照片/商品，并不天然意味着少存了某张特定原图。此类使用条件另行说明；已看过的对照图也不自动等于保存了独立输入文件。

所有已保存原图、原文和旧版本继续留在本仓库，新增说明与分类放在独立元数据中。来源消失时仍能读取既有文件；已知缺项不会被“文件存在”检查掩盖。原有文件没有为了本次复核而删除。
